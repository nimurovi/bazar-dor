# BazarDor

### Know Today's Market Prices at a Glance

**BazarDor** is a web application that helps users explore and compare the prices of everyday essential products in Bangladesh. It provides an easy way to check current market prices, review historical price changes, and understand market trends.

## Key Features

1. **Current Market Prices** — Browse the latest available prices of essential products in one place.
2. **Price History and Trends** — Compare today's prices with yesterday, last week, and last month to understand price fluctuations.
3. **Category-Based Browsing** — Explore products through organized categories for easy navigation.
4. **Market-Wise Price Comparison** — Compare minimum and maximum product prices across different markets and divisions.
5. **Dynamic Product Details** — View individual product information and explore price data through dynamic routes.

## Technologies Used

- **Next.js 16** — React framework for routing and server-side rendering.
- **React** — Component-based user interface development.
- **TypeScript** — Type safety and maintainable code.
- **Tailwind CSS** — Responsive styling and UI design.
- **REST API** — Fetching product, category, and market-price data.
- **JavaScript (ES6+)** — Modern JavaScript functionality.
